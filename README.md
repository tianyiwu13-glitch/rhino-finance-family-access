# Rhino Finance family access probe

This is a static connectivity test page for the Rhino Finance project. It contains only a public project title, an explanation of the test and a preparation date.

It contains no credentials, databases, videos, transcripts, screenshots, visitor information, financial opinions, external scripts or tracking. It performs no network calls from the page.

Opening the page on the intended family's mobile network is the acceptance test. Publishing it does not by itself establish availability in mainland China, permanent stability, automatic updates or a complete website migration.

The existing production website and private cloud PoC repository are separate and must remain unchanged.
